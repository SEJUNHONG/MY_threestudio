# 포트폴리오 기여 범위

## 기존 코드에서 확인되는 내용

SD SDS 경로, MVDream·ImageDream 가이던스, NeRF·Gaussian 렌더러, 이미지 경로를 포함한 prompt processor 확장이 있습니다. 이는 여러 연구 구현을 하나의 프레임워크에서 실험하려는 통합 작업의 근거입니다.

별도 멀티뷰 파인튜닝 학습 로그·체크포인트·데이터 분할, 시점 일관성 향상 수치, NeRF 대비 3DGS 실측 속도는 이 공개 저장소에서 확인되지 않습니다. 다른 곳에 보유한 당시 기록이 있다면 그 근거를 추가해 설명할 수 있습니다.

## 이번에 새로 수행한 작업

3DGS 배경/배치 오류, background gradient 연결, optimizer와 topology 변경 순서, ImageDream 조건 및 SDS schedule 초기화, 체크포인트 통계 보존을 수정했습니다. 공통 실행기, 사전 진단, CPU 회귀 테스트 및 사전학습 ImageDream cross-attention 추가 학습 스크립트를 작성했습니다. 이를 재직 당시 이미 완료한 실적으로 소급하지 않습니다.

## 현재 근거에 맞는 소개 문장

> NCSOFT Multimodal AI Lab에서 텍스트·이미지 조건 3D 생성 파이프라인을 연구했습니다. threestudio 기반으로 SD SDS, MVDream·ImageDream 가이던스와 NeRF·3DGS 표현을 연결하는 실험 환경을 구성했습니다.

후속 정리까지 설명할 때:

> 3DGS 렌더링과 이미지 조건 전달에서 발생한 텐서·최적화 순서 오류를 보완하고, 공통 실행 도구와 회귀 테스트, 추가 학습 진입점을 마련했습니다.

## 측정 후 사용할 수 있는 표현

- 동일 조건의 벤치마크가 있으면: “NeRF 대비 3DGS 렌더링 시간을 X에서 Y로 단축.” 현재 X/Y를 채우지 않습니다.
- 독립 테스트셋 결과가 있으면: “멀티뷰 파인튜닝으로 지표 A를 B만큼 개선.” 현재 해당 실험 증거는 없습니다.
- Cross-attention은 ImageDream이 제공하는 메커니즘입니다. 자체 설계와 공개 모델 통합의 범위를 구분합니다.

회사 내부 자료·서비스 주소가 없어도 공개 가능한 코드의 문제 발견, 수정 이유, 검증 범위를 설명하는 것으로 기술적 기여를 보여줄 수 있습니다.
